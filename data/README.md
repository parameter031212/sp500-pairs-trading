# 입력 데이터

원본 데이터는 이 저장소에 포함하지 않습니다. 적법하게 사용할 수 있는 파일을 이 폴더에 두거나 `--data-dir`로 연결합니다.

## 가격

```csv
date,AAPL.US,MSFT.US
2015-01-02,가격,가격
```

첫 열 `date`, 나머지 열은 종목별 양의 일별 수정종가입니다. 결측은 빈 값으로 유지합니다.
실제 입력에는 숫자를 사용해야 합니다. 가격은 전방·후방 보간하지 않습니다.
정규화 후 같은 날짜/종목이 중복되거나 0 이하·무한 가격이면 오류입니다.
시장 전체 날짜가 파일에서 빠진 경우는 이 파일만으로 판별할 수 없으므로 공급 달력의 완전성이 필요합니다.

수정종가는 연구상 일관된 체결·손익 대용 가격으로 사용합니다. 원시 가격, 분할 수량, 배당 현금, 상장폐지 수익을 복원한 실제 체결 원장은 아닙니다.
배당 조정이 이미 반영된 가격에 배당을 다시 추가하지 않습니다. 공급자의 조정 범위 확인이 필요합니다.

## 구성종목

```csv
date,tickers
2015-01-02,"AAPL,MSFT,..."
```

각 행은 그 날짜부터 유효한 전체 구성종목 목록입니다. 편입/편출 변경분만 있는 파일은 그대로 사용할 수 없습니다.
실제 파일에서는 ... 대신 전체 목록이 있어야 합니다. 포메이션 종료일보다 늦지 않은 가장 최근 스냅샷을 사용합니다.
2015~2024 전체 가격 커버리지로 생존 종목만 골라 놓지 않습니다. 커버리지는 각 포메이션 안에서 계산합니다.

## 섹터

고정 매핑은 `ticker,sector`입니다. 이 경우 결과에 `static_not_historical`을 기록합니다.
과거 매핑은 `date,ticker,sector`입니다. 각 종목에 대해 포메이션 종료일까지 알려진 가장 최근 행을 사용합니다.
고정 매핑을 과거 GICS라고 부르거나, 서로 다른 분류체계를 자동으로 11개 GICS 섹터로 간주하지 않습니다.
미분류 라벨은 설정의 `unknown_sectors`로 제외하며 제외 내역을 남깁니다.

## 식별과 품질

티커의 대소문자·공백·`.US` 접미사와 클래스 표기 `.`/`/`를 정규화합니다.
이것은 영구 종목 식별자(PERMNO 등)를 대체하지 않습니다. 티커 재사용·합병·분할의 이력은 별도 검증 대상입니다.
1일 50% 초과 가격 변동 건수는 입력 진단에 기록할 뿐, 미래의 급등락을 보고 과거 종목을 자동 제외하지 않습니다.
보유 중 가격이 없으면 결과를 만들어내지 않고 오류와 해당 페어·날짜를 기록합니다.

연구 품질의 실증에는 역사적 구성종목뿐 아니라 상장폐지 가격, 조정 범위, 섹터 시점, 종목 식별도 함께 검증해야 합니다.
