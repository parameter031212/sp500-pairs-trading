# 거래·통계·회계 명세

## 1. 시간과 정보

날짜는 일별 시장 관측 날짜다. 달력은 가격 파일의 행을 사용한다. 공급 파일에 전체 시장 달력이 포함되어 있어야 한다.
12개월/6개월은 달력 개월이며 252/126개 행으로 바꾸지 않는다. 각 구간은 시작 이상, 다음 시작 미만이다.
포메이션 자료는 거래 구간 시작보다 이르다. 각 포메이션 마지막 관측일까지 유효한 가장 최근 구성종목 스냅샷을 선택한다.
스냅샷의 공표 지연 정보가 없는 입력에는 시점 가정이 남는다.

각 구간에 가격 이력과 최소 관측치가 필요하다. 설정 종료일 이후까지 이어지는 마지막 불완전 거래 구간은 제외한다.
평가 분할을 선택해도 원래 거래 구간 격자는 유지하며 그 분할 안에 온전히 들어오는 구간만 실행한다.
실제 실행 구간은 `windows.csv`와 성과의 최초·최종 날짜에 기록한다.

## 2. 포메이션

1. 당시 S&P500 종목 중 가격 열·알려진 섹터·포메이션 커버리지·관측 수 조건을 점검한다.
2. 개별 로그가격 및 차분의 ADF 진단을 저장한다. I(1) 필터의 기본값은 false다.
3. 같은 섹터의 순서 없는 모든 종목 조합을 후보로 만든다. 상관·HR·반감기 필터 전에 검정한다.
4. 기본 방향은 정규화된 종목 식별자의 사전식 순서: 작은 종목 X, 큰 종목 Y.
5. `log(P_Y) = alpha + beta log(P_X) + S`를 상수항 포함 OLS로 추정한다. 추세항은 사용하지 않는다.
6. EG 검정의 올바른 p값을 사용한다. 일반 잔차 ADF의 p값을 공적분 p값으로 대체하지 않는다.
7. std는 표본 표준편차(ddof=1), mean은 표본 평균이다. 상수항 회귀의 mean이 거의 0이어도 값을 저장한다.
8. `S_t = c + phi S_(t-1) + error`로 AR(1)을 추정한다. `0<phi<1`에서만 반감기 `-log(2)/log(phi)`를 계산한다.
9. 상관계수는 원래 시장 달력에서 인접 관측의 일별 로그수익률 상관이다.
10. 지정된 유의수준·상관·β·반감기와 선택적 I(1) 필터를 적용한다.
11. EG t 통계량이 작은 순서로 방문해 집중 한도에 걸리지 않는 페어를 최대 개수까지 선정한다. 동률은 페어 식별자로 처리한다.

스프레드 적합에는 두 가격이 모두 있는 포메이션 관측을 사용하고 생략된 관측 수를 기록한다.
결측이 허용되면 잔차 ADF와 반감기의 간격은 완전한 일별 자료와 다를 수 있다. `min_formation_coverage=1.0`으로 무결측 강건성을 비교할 수 있다.
미래 구간의 가격 결측이나 수익률은 포메이션 필터에 쓰지 않는다.

양방향 옵션은 각 방향 EG p값 중 작은 것을 선택하고 `pair_p = min(1, 2*min(p1,p2))`로 보정한다.
수치 적합 실패는 통과로 처리하지 않는다. 경제적 필터를 통과하는 방향을 다시 골라 바꾸지 않는다.
이 보정은 한 페어의 두 방향 탐색에 대한 것이다. 기본 `multiple_testing=none`은 다수 페어 전체에 대한 오류확률 5%를 주장하지 않는다.
Holm/BY 실험은 가격·섹터 커버리지로 정의된 모든 후보 페어에 먼저 적용하고 경제적 필터를 뒤에 적용한다.
입력 I(1)·유한표본·의존성 가정이 맞아야 통계적 오류율 해석도 가능하다.

## 3. 신호와 체결 순서

포메이션 마지막 종가로 처음 신호를 만들 수 있다. 이 경우 첫 거래일 종가에 체결한다.
매 거래일 처리 순서는 다음과 같다.

1. 이전부터 보유한 수량으로 전일 종가부터 오늘 종가까지 평가손익을 반영한다.
2. 그 기간의 현금 수익 또는 공매도 비용을 반영한다.
3. 전일 종가에 결정한 주문을 오늘 종가로 체결하고 비용을 차감한다.
4. 오늘 종가로 모니터링하고 다음 거래일 종가 주문을 결정한다.

오늘 새로 체결한 진입은 오늘 종가 이전의 수익을 얻지 않는다. 청산되는 기존 포지션은 오늘 종가까지의 가격 변화를 부담한다.
전일 확정한 주문을 오늘 종가의 Z를 보고 소급 취소하지 않는다. 가격 갭이 있으면 진입이 손절 경계 밖이나 평균 반대편에서 체결될 수 있다.
그런 경우 새 정보로 다음 거래일 청산 주문을 낼 수 있지만 체결가를 과거 신호 가격으로 되돌리지 않는다.

## 4. 매매 상태

`Z = (S - formation_mean) / formation_std`. α·β·평균·표준편차는 구간 중 갱신하지 않는다.
양의 β만 거래한다. Z가 높으면 숏 Y·롱 X, 낮으면 롱 Y·숏 X다.

- 빈 포지션: `|Z| >= entry_z`이면 진입 후보. 활성 손절이 있으면 `|Z| < stop_z`도 필요하다.
- 롱 스프레드: `Z >= -exit_z`이면 회귀 청산, `Z <= -stop_z`이면 활성 손절.
- 숏 스프레드: `Z <= exit_z`이면 회귀 청산, `Z >= stop_z`이면 활성 손절.
- 하루 가격이 경계를 건너뛰어도 관측된 조건으로 다음 종가 주문을 낸다. 경계 가격 체결을 가정하지 않는다.
- 손절 기준은 계좌 손실률이 아니라 고정된 스프레드의 Z 기준이다.
- 최대 보유기간 H는 진입 체결일을 1일로 센다. H-1번째 거래일 종가에 주문을 예약해 H번째 거래일 종가에 청산한다.
- 거래 구간 마지막 종가 청산은 미리 알려진 일정이다. 마지막 종가에서 신규 진입하지 않는다.
- 한 페어에 한 포지션만 허용한다. 물타기와 청산 체결 당일의 신규 진입 신호는 없다.
- 평균회귀 청산 이후에는 다음 관측부터 신규 신호를 허용한다.
- 손절·시간청산 후 `block_window`면 해당 구간 재진입 금지. `after_reset`이면 청산 다음 관측부터 진입 경계 안 복귀를 확인한 뒤 새 신호를 기다린다.

겹치는 청산 사유의 기본 우선순위는 회귀, 방향별 손절, 탐지기, 보유기간이다.
마지막 날짜에는 기존 청산 주문이 있으면 그 사유를 유지하고, 없으면 window_end로 기록한다.

## 5. 수량·자금·비용

구간 시작 전체 NAV를 최대 페어 수 N으로 나눈 슬롯자본을 배정한다. 선정 페어가 K<N개면 N-K개 슬롯은 현금이다.
선정되지 않은 슬롯 때문에 거래하는 페어의 자본을 키우지 않는다. 다음 구간 시작에만 전체 NAV를 재분배한다.
각 슬롯은 자기 손익으로 변하며 다음 진입에는 그때 슬롯 NAV C를 사용한다.

롱 스프레드 방향 d=+1, 숏 스프레드 d=-1에 대해 다음 진입 금액을 사용한다.

```
N_Y = d * C / (1 + beta)
N_X = -d * beta * C / (1 + beta)
q_Y = N_Y / execution_price_Y
q_X = N_X / execution_price_X
```

진입 gross는 비용 차감 전 슬롯 NAV와 같다. β는 항상 X의 금액에 대응하며 단순히 공매도 쪽에 곱하지 않는다.
수량은 청산까지 고정한다. 일별 손익은 `q_X * price_change_X + q_Y * price_change_Y`이며 로그스프레드 차분을 수익으로 직접 쓰지 않는다.
로그가격 헤지는 수익률 변화에 대한 근사다. 고정 수량은 매일 동일한 로그수익률 비중을 완벽하게 추적하지 않는다.
회귀계수 β는 시장베타가 아니며 시장베타 중립을 보장하지 않는다.

계좌 NAV에는 순매수/공매도 금액을 상쇄하는 현금 잔액이 암묵적으로 포함된다.
현금 이자는 포지션이 없는 슬롯에만 지급한다. 포지션 보유 중 별도 금융·증거금 이자와 공매도 담보 이자는 모델링하지 않는다.

거래비용은 양쪽 실제 거래금액 합계에 `(commission_bps + slippage_bps)/10000`을 곱해 차감한다.
슬리피지는 별도 금액 비용이며 가격을 동시에 또 조정하지 않는다. 양쪽 합계 gross=C라면 5bp 진입 비용은 0.0005C다.
청산 gross는 가격 변동 후 수량의 실제 평가금액으로 계산한다.
공매도 비용은 전일 공매도 평가금액에 연이율과 경과 달력일/365를 곱한다. 주말도 반영한다.
소수 주식 수량을 허용한다. 실제 주식 단위·최소 주문·대차 가능 수량·세금·시장충격은 별도 확장 범위다.

## 6. 예외와 성과

보유 중 필요한 가격이 없으면 실행을 중단하고 failed 상태를 남긴다. 마지막 가격으로 가상 청산하거나, 그 종목의 손실을 지우지 않는다.
진입 체결일에 한쪽 가격이 없으면 진입 주문을 취소하고 기록한다. 포지션이 없으면 그 슬롯은 현금이다.
NAV가 0 이하가 되면 지급불능으로 중단한다. 레버리지 손실을 임의로 0에서 제한하지 않는다.

각 구간의 모든 시장 관측을 포함한다. 총 NAV의 일별 변화율을 일별 포트폴리오 수익률로 사용한다.
연 수익률은 기하 연율화, 변동성은 표본 표준편차, 샤프는 전체 일별 초과수익의 평균/표준편차로 계산한다.
최대낙폭의 최초 고점에는 거래 전 초기자본도 포함한다. 첫날 거래비용으로 인한 하락도 누락하지 않는다.
수익률 단위는 소수이며 0.01은 1%다. 현금·빈 슬롯·선정 실패도 결과의 일부다.
