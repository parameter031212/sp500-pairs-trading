# B모델: 공적분 + 상관계수

2026-09-19 팀 공유 설정. 실행 파일은 `configs/model_b.toml`이다. 기업 검수와 다중검정을 추가하기 전의 비교 기준모델이다.

## 페어 선정

선정 당시 S&P500에 속하는 종목의 동일 섹터 내 조합을 검사한다. 과거 12개월의 조정종가를 로그로 변환하고, 상수항을 포함한 OLS로 `log(Y) = alpha + beta * log(X) + spread`를 추정한다. 회귀 방향은 종목 코드 정렬에 따라 고정한다.

| 항목 | 조건 |
|---|---|
| Engle-Granger 공적분 | p < 0.05 |
| 일별 로그수익률 상관계수 | > 0.5 |
| 헤지비율 beta | 0.3 이상 3.0 이하 |
| AR(1) 평균회귀 반감기 | 5~30거래일 |
| 추정기간 자료 확보 | 99% 이상, 최소 120개 관측치 |
| 최종 순위 | EG 검정통계량 오름차순 |
| 전체 선정 수 | 최대 20페어 |
| 섹터당·종목당 페어 수 | 제한 없음; 설정값 0 |

다중검정 보정, 기업 검수, 왜도·첨도 필터, 사전 거래 샤프 필터는 이 B모델에 적용하지 않는다. 개별 종목 I(1) 진단은 기록하지만 필수 통과 조건으로 사용하지 않는다. 실제 입력의 섹터가 고정 분류이면 역사적 섹터 분류라고 해석하지 않는다.

## 거래와 위험 관리

추정 후 6개월 동안 거래하고, 다음 6개월 구간에서 다시 선정한다. 구간은 겹치지 않는다. alpha, beta, 스프레드 평균과 표준편차는 거래 구간 동안 고정한다.

`Z = (현재 spread - 추정기간 평균) / 추정기간 표준편차`

| 방향 | 진입 | 포지션 | 평균회귀 청산 | 손절 |
|---|---|---|---|---|
| 양의 Z | 2 <= Z < 3.5 | Y 매도, X 매수 | Z <= 0 | Z >= 3.5 |
| 음의 Z | -3.5 < Z <= -2 | Y 매수, X 매도 | Z >= 0 | Z <= -3.5 |

- 당일 종가 신호는 다음 거래일 종가에 체결한다. 신호 경계에서 체결됐다고 가정하지 않는다.
- 최대 보유기간은 체결일부터 60거래일이며, 거래 구간 종료 시 남은 포지션을 청산한다.
- 평균회귀 청산 후에는 재진입할 수 있다. 손절·시간청산 후에는 해당 거래 구간 재진입을 막는다.
- 확인된 합병 발표 대상 종목은 신규 진입을 막고 보유 페어 양쪽을 청산한다. [일정표의 범위와 시점 규칙](../reference_data/README.md)을 따른다.
- 구간 시작 자본을 20개 슬롯으로 동일 배분한다. 미선정 슬롯은 현금으로 두며 선정 페어의 자본을 늘리지 않는다. 각 페어의 두 레그 절대 투자금 합계는 진입 시 슬롯자본과 같다.
- 각 레그 매매금액에 수수료 5bp를 적용한다. 기본 슬리피지·대차비용·현금이자는 0이다.

3.5시그마는 초기 실험의 설정값이며, 최적 손절선이나 계좌 손실률 3.5%를 뜻하지 않는다. [상세 통계·회계 명세](specification.md)와 [설계 결정 기록](decisions.md)을 함께 참고한다.

## 실행

Python 3.11 이상에서 저장소 루트 기준으로 실행한다.

```bash
python -m pip install -r requirements.txt
python run_backtest.py check-data --config configs/model_b.toml --data-dir "/path/to/data"
python run_backtest.py run --config configs/model_b.toml --data-dir "/path/to/data" --max-windows 1
```

첫 구간 점검이 끝나면 `--max-windows 1`을 빼고 전체 기간을 실행한다. 필요한 세 입력 파일은 [데이터 안내](../data/README.md)를 참고한다. 원본 가격·구성종목·섹터 데이터는 Git에 포함하지 않으며 각 팀원이 별도로 준비한다.

노트북에서는 `notebooks/Start_Here.ipynb`를 열고 다음 두 항목을 수정한다. 커널을 재시작하고 위에서부터 실행한다.

```python
CONFIG_FILE = "configs/model_b.toml"
DATA_DIR = Path("/path/to/data")
```

노트북의 `PARAMETERS`가 설정 파일보다 우선한다. B모델 기준값은 추정 12개월, 진입 2, 청산 0, 손절 3.5, 보유 60일, 집중 제한 0이다. 날짜 기본값은 기존 베이스라인의 2016-01-01~2024-12-31이며 연구 기간은 별도로 지정할 수 있다.

실제 데이터 없이 소프트웨어 실행을 확인하려면 아래처럼 가상 자료를 사용한다. 결과는 S&P500 성과가 아니다.

```bash
python run_backtest.py run --config configs/model_b.toml --set 'data.mode="synthetic"' --set 'schedule.end="2016-06-30"' --max-windows 1
```

실행 결과는 `results/model_b/` 아래 실행별 폴더에 저장된다. A-D의 144개 파라미터 탐색은 [별도 실험 안내](selection_study.md)를 참고한다.
