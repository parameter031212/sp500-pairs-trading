# 배포 전 검증 기록

2026-09-11, 버전 0.1.0. 아래는 소프트웨어 동작 검증이며 최종 실증 성과 보고서가 아니다.

| 검증 | 결과 |
|---|---|
| 자동 검증 | 25개 통과 |
| 가상 데이터 기본 실행 | 2016~2018년 6개 구간, 782개 관측일, 143개 완료 거래 |
| 가상 데이터 조합 비교 | 진입 1.5/2.0 × 손절 3.5/4.5, 4개 조합 모두 완료 |
| 시작용 노트북 | 5개 코드 셀을 IPython에서 순서대로 실행, 오류 없음 |
| 패키지 | wheel 생성 및 분리된 임시 폴더에서 가져오기·설정 검증·가상 1개 구간 실행 성공 |
| 실제 입력 데이터 연결 | 2016년 상반기 1개 구간 완료: 9,689개 후보 검정, 20페어 선정, 26개 완료 거래 |

자동 검증에는 다음날 체결, 진입일 이전 손익 배제, 두 방향의 β 배분, 실제 거래금액 비용, 주말 대차비용,
손절 기준·사용 여부 변경, 평균회귀 후 재진입, 최대 보유일, 손절 후 재진입 정책,
EG 검정 p값, 미래 데이터 변경에 대한 포메이션 불변성, 양방향 탐색 보정,
집중 한도, 빈 슬롯 현금, 손익 대사, 무거래 결과 파일, 탐지기의 순차 관측과 청산 지연을 포함한다.

가상 조합 실험의 완료 거래 수는 각각 225, 237, 143, 148개였다.
설정 변경이 기록에만 남는 것이 아니라 거래 결과에도 반영되는지 확인했다. 이 숫자로 실제 시장의 최적 파라미터를 선택하지 않는다.

실제 데이터는 가격·과거 구성종목·섹터의 세 입력 파일을 사용했다. 원본은 수정하지 않았으며 공유 배포본에도 포함하지 않는다.
2016~2024년 전체 18개 구간을 모두 실행한 것은 아니다. 입력의 고정 섹터 분류, 조정가격, 종목 식별 및 상장폐지 처리 한계도 남아 있다.

실행 환경의 소켓 제한 때문에 별도 Jupyter 커널을 띄우는 방식은 완료하지 못했다.
대신 같은 Python 환경의 IPython 안에서 실제 노트북 코드 셀 전체를 순서대로 실행했다.
GitHub Actions 설정은 포함했지만 원격 저장소에서 실행된 결과는 아직 없다.

검증에 사용한 주요 환경은 Python 3.12이며, numpy 2.5.2, pandas 3.0.5, scipy 1.18.1,
statsmodels 0.15.0, matplotlib 3.11.1이다. 의존성 허용 범위 전체를 검증했다는 뜻은 아니다.
개별 실행의 정확한 버전·코드 해시·입력 해시는 `manifest.json`에 저장된다.
